# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v0.20.3 | :white_check_mark: |
| < v0.20.3 | :x:             |

## Reporting a Vulnerability

If you discover a security vulnerability in Quasar, please report it privately.

- **Do not open a public issue.**
- Contact: `vedhashiva231@gmail.com`
- Provide a description, steps to reproduce, and potential impact.

We will acknowledge within 48 hours and aim to triage within 7 days.

## Scope

Security reports related to code generation, compiler crashes, or unsafe C output are appreciated.

## Credits

Vulnerability reporters will be acknowledged in the repository if desired.
